# hmc002.github.io

Static files served by GitHub Pages at `https://hmc002.github.io`.

This repository is public. It is a published copy only: the files are maintained in a private repository and copied here by pull request. Do not edit them here.

It holds no keys, no service addresses and no personal data.

| Path | Purpose |
|---|---|
| `inbox-desk-reply/` | Web files for an Outlook add-in |
| `.well-known/microsoft-officeaddins-allowed.json` | Tells classic Outlook on Windows which add-in script may make web requests |
| `.nojekyll` | Makes GitHub Pages serve the `.well-known` folder |
| `index.html` | Placeholder home page |
